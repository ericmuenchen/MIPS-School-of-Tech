One-liner: The MIPS signature accent — a navy line icon sitting on a maize rounded square.

```jsx
<IconSwatch>
  <svg width="19" height="19" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><rect x="3" y="4" width="18" height="18" rx="2"/></svg>
</IconSwatch>
```

Icons should be single-weight outline (Lucide-style) and inherit navy via `currentColor`. `size` (px) and `radius` are adjustable.
