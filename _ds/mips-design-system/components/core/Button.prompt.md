One-liner: MIPS pill button — solid navy (default), maize (one CTA per screen), or outline (secondary).

```jsx
<Button variant="solid">Enroll now</Button>
<Button variant="maize">Get started</Button>
<Button variant="outline" size="sm">Learn more</Button>
```

Variants: `solid` | `maize` | `outline`. Sizes: `sm` | `md` | `lg`. Always pill-shaped; hover deepens the color one step. Reserve `maize` for a single primary action.
