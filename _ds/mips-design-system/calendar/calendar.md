# MIPS Academic Calendar — 2026–2027

Source: **MIPS Staff Calendar 2026-2027** (`uploads/calendar-2026-2027.pdf`). Structured data lives in `calendar/calendar-2026-2027.json`. These are the student-facing academic dates a course syllabus needs.

**Every MIPS syllabus covers exactly one semester** — Fall (Semester 1) or Winter (Semester 2). When a user uploads course content, fit it into the chosen semester's instructional weeks below, inserting each break as a "no new lessons" row in the schedule table.
