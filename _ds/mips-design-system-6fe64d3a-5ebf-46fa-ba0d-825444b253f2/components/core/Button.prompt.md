Pill-shaped button, MIPS's primary interactive control, use for CTAs and nav actions.

```jsx
<Button variant="outline">Student Login</Button>
<Button variant="solid" size="lg">Get Started</Button>
<Button variant="maize" icon={<IconStar />}>Enroll Now</Button>
```

Variants: `outline` (default, thin navy border, white bg, dark text; matches "Student Login" on the real site), `solid` (navy fill for the single strongest CTA per screen), `maize` (yellow fill, use only for one high-energy highlight moment, never body text). Sizes: `sm`, `md`, `lg`. Never use square/heavily-filled buttons, MIPS buttons are always pills with thin outlines.
