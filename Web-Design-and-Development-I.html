Course Description

Web pages are how ideas get shared today, and knowing how to build one is a useful skill in almost any career. This project-based course teaches you to build your own web pages from the ground up. You’ll write real code (no templates or drag-and-drop) and by the end of the semester you’ll understand how web pages are created, viewed, and fixed, and you’ll have a live personal website to prove it.

This first semester is all about foundations. You’ll start with how the web works, then learn HTML to structure pages and CSS to style them. You’ll pull those skills together in a Homepage portfolio project, then push into advanced HTML & CSS (semantic structure, filters, animation, and interaction) and finish by building an animated, interactive “Tell a Story” page. Semester II picks up with Bootstrap, responsive design, and user-interface design.

How This Course Works

This is an asynchronous online course delivered through CodeHS, where you’ll write and publish HTML and CSS right in the browser, with nothing to install. Each unit is broken into lessons made of short video tutorials, quick quizzes, example pages to explore, and hands-on exercises where you build and publish your own sites. Assignments, feedback, and announcements live in Google Classroom. Work through lessons at your own pace, but keep up with the weekly checkpoints on the schedule so projects don’t stack up.

Use Chrome for the best experience

Browsers render HTML and CSS a little differently, so do your coding in an up-to-date version of Google Chrome. It’s free, and it’s what the CodeHS editor is built and tested against.

What You'll Learn

How the Web Works

Explain what the Internet is, what a URL points to, and the steps a page takes to reach your screen.

Structure with HTML

Build pages with tags, attributes, and elements: text, links, images, lists, and tables.

Style with CSS

Select elements by tag, class, and id, and reason about the cascade to control how a page looks.

Make It Interactive

Use semantic layout, image filters, animation, and hover and click effects to bring pages to life.

Grading

Your grade is built from lesson exercises, unit quizzes, and two portfolio projects, weighted toward the work you build, publish, and revise. These are the graded pieces this semester:

  2. CSS styling exercises

Course Policies

Pacing & deadlines

The course is self-paced, but the schedule’s weekly checkpoints keep you on track to finish the semester. If you fall behind, don’t panic: message me and we’ll make a plan to catch up. Steady weekly progress beats last-minute cramming every time.

Late work & revision

Late work is accepted: getting it right matters more than getting it in first. Because coding is about iteration, you may revise and resubmit exercises and projects to improve your grade. Growth counts here more than penalties.

Communication

Email me or book a 1:1 through the scheduling link above; I usually reply within one school day. Lessons and exercises live in CodeHS, and feedback, grades, and announcements live in Google Classroom; check both regularly.

AI Policy

The goal is for you to be able to write and understand the code.

AI tools can explain a concept or help you find a bug, and used that way they’re a great tutor. But if the tool writes the page for you, you haven’t learned to build web pages, which is the entire point of this course. Lean on AI to understand, not to replace the work.

  • You may use AI to explain concepts, define terms, or help you understand an error message.
  • Do not paste AI-generated HTML or CSS in as your own: submitted code should be code you can read and explain.
  • I may ask you to walk me through how your project works; if you built it, that’s an easy conversation.
