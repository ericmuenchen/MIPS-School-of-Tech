Course Description

PC Pro A is a hands-on introduction to how computers are built, configured, and supported, and the first step toward the CompTIA A+ certification that IT professionals earn. This first semester focuses on the physical and foundational side of computing: choosing and installing hardware, working safely and professionally as a technician, and setting up operating systems and storage. You'll read, watch demonstrations, and practice in TestOut LabSim's simulated computer environment, so you build real skills without needing a room full of hardware.

The term moves in a logical build order. You'll start with a Course Introduction and the PC Technician's Responsibilities (safety, professionalism, and the six-step troubleshooting method), then dig into Hardware the components inside every machine. From there you'll install and navigate Operating Systems and Storage, plan a real System Implementation (including cloud and virtualization), and finish with System Management the tools that keep a running system healthy.

How This Course Works

This course is fully asynchronous: there are no required live sessions, so you can do the work when it fits your schedule. Announcements and feedback come through email and Google Classroom, and the lessons, labs, and quizzes themselves live in TestOut LabSim. I'll set weekly checkpoints to help you stay on pace across the seven sections we cover this semester.

Optional weekly meetup

Each week I host an optional 30-minute meeting where you can share projects, connect with classmates, play games, and discuss emerging technologies. It's not required, but it's a fun way to stay connected to the class.

What You'll Learn

By the end of this semester you'll be able to open up a computer, understand every major part inside it, and set one up from bare hardware to a running, managed operating system, the same core skills an entry-level IT technician uses every day.

Build the hardware
Identify, select, and install the components inside every PC, from the motherboard out.
Set up the system
Install and navigate operating systems and storage, then plan a real deployment.
Work like a technician
Practice safety, professionalism, ticketing, and a repeatable troubleshooting method.
  • Select and install PC hardware: motherboards, CPUs and cooling, RAM, power supplies, and expansion cards
  • Configure BIOS/UEFI, the boot sequence, and firmware updates
  • Follow ESD and physical safety protocols and use power protection like UPS and surge protectors
  • Create, update, and close support tickets and document work using the six-step troubleshooting method
  • Install and navigate Windows, macOS, and Linux operating systems
  • Install and configure storage (HDD, SSD, NVMe, M.2) and set up RAID 0, 1, 5, and 10
  • Plan a Windows deployment and set up virtual machines and cloud services (IaaS, PaaS, SaaS)
  • Manage a running system with Task Manager, Resource Monitor, the command line, and virtual memory

Grading

Your grade is your total score across assignments, projects, and quizzes. Each week you'll get a progress report showing two numbers: your overall grade, which reflects only the work you've turned in so far, and your relative grade, which also counts anything not yet submitted as a zero — in other words, what your grade would be if the semester ended today.

Course Policies

Pacing & deadlines

Weekly targets keep your progress steady, but you're welcome to work ahead. If you fall behind, reach out early and we can build a plan to help you catch up before the semester ends.

Late work

Because this course is fully asynchronous, there is no penalty for late work. The weekly schedule is a pacing guide to help you stay on track over the semester, not a set of hard deadlines. Staying close to the pace keeps the workload manageable and makes sure you finish every project before the term ends.

Communication

Email me anytime at muenchen@miprepschool.org or send me a Google chat. I typically respond within one school day.

AI Policy

The goal is for you to learn to think like an IT technician, not to submit answers you can't explain.

AI tools can be great tutors, and IT professionals use AI as a standard part of their workflow. But you are just at the beginning of your IT education, and the CompTIA A+ exam expects you to know this material yourself. If AI does all the work and thinking for you, learning never happens.

Here is how to acceptably use AI in this course:

  • Use AI to explain a concept, decode an error message or beep code, or ask "why doesn't this work?" — not to answer quiz or lab questions for you.
  • You should be able to explain every answer you submit. If it looks like answers were copied without understanding, I will ask to meet with you so you can walk me through your reasoning.
  • When in doubt, ask me first. I would much rather help you than have you turn in work you cannot explain.
